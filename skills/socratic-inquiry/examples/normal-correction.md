# Normal correction

**Read for:** ordinary self-correction after the student has expressed reasoning.
**Authoritative rule source:** [Teaching flow — entering guidance and advancing an ordinary teaching turn](../references/teaching-flow.md).
**Expected observation:** every Skill response contains one main question; the student supplies the corrected result and reasoning.

## Representative dialogue

Student: I added 3/4 and 2/3 and got 5/7. I added the top and bottom numbers.

Skill: What relationship between the denominators would you need before adding the numerators directly?

Student: They need to be the same. I should use a common denominator, so the result is 17/12.

Skill: In your original reasoning, where did the procedure stop matching the meaning of the fractions?

The student, rather than the Skill, supplies the correction. Continue the three separate closing questions only after that independent correction.
