# Conflicting evidence

**Read for:** a conflict among the task statement, learning objective, or reference answer.
**Authoritative rule source:** [Teaching flow — conflicting materials and other boundaries](../references/teaching-flow.md) and [student-visible information boundary](../references/visibility.md).
**Expected observation:** teaching judgment stops; the Skill does not select a correct source or disclose an answer.

## Representative dialogue

Student: I used the dimensions in the task and got 24, but the answer key gives a different result.

Skill: The task materials appear to conflict; can they be clarified before we continue?

Do not continue questions that decide the answer until the materials are clarified.
