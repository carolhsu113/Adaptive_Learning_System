# Representative cases

Use a case only to interpret a boundary or check regression behavior. The authoritative teaching rules are in [the teaching flow](../references/teaching-flow.md); disclosure limits are in [the visibility boundary](../references/visibility.md). These cases do not define another teaching process.

| Case | Read when | Authoritative rule source | Expected regression observation |
|---|---|---|---|
| [Normal correction](normal-correction.md) | Checking ordinary self-correction | Teaching flow — entering guidance, ordinary turns, and closing reflection | Each ordinary Skill response has one main question; the student supplies the correction and later reflections. |
| [Answer request](answer-request.md) | Checking a request for an answer or steps | Teaching flow — answer requests; visibility boundary — prohibited disclosure | The response withholds the answer and asks one inspectable question. |
| [Insufficient reasoning](insufficient-reasoning.md) | Checking a student who gives too little reasoning | Teaching flow — entering guidance and insufficient reasoning | The response asks for one concrete step without completing the reasoning. |
| [Conflicting evidence](conflicting-evidence.md) | Checking inconsistent task materials | Teaching flow — conflicting materials; visibility boundary — conflict disclosure | Teaching judgment stops without selecting a correct source or revealing the answer. |
| [Completion wrap-up](completion-wrap-up.md) | Checking reflection after independent correction | Teaching flow — independent correction and closing reflection | Cause, prevention rule, and transfer checkpoint are asked in three separate turns and in order. |

The package adds no language-continuity or out-of-scope example because the regression artifacts `english-past-tense-004.json` and `live-exam-cheating-008.json` already cover those boundaries. See the SK-01 verification record for the full artifact map.
